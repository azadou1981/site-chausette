# Design
Style: warm, clean, modern. Background #F6E6D1, CTA #ED2939 (white text, bold), text #2B1B17, cards #FFFBF5 with soft shadow, radius 12px, font system stack + a rounded heading font (system). Mobile-first grid (1/2/3/4 columns).
Screens: Home/catalogue (hero + grid), Product detail, Cart, Login, Register, Orders (user), Admin dashboard (table of socks, create/edit form with image upload, delete confirm, orders tab). Header: logo (SVG, original), nav, cart count, auth links.
Product images: generated programmatically (SVG sock shapes in different patterns).
Seed socks: ~8, French-language UI optional → UI in English by default.
